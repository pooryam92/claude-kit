# dotclaude


| Plugin | What it does |
| --- | --- |
| `dotopen` | `/dotopen` opens the current directory in VS Code. Needs `code` on your `PATH`. |
| `dotupdate` | `/dotupdate` syncs your dotclaude plugins with this repo: installs new ones, removes old ones, updates the rest, reloads. |
| `dotbrainstorm` | "Let's brainstorm X" or "come up with ideas for X": strips the goal down to first principles, invents three ordinary people who meet that core, drafts ten idea titles through their eyes, makes the titles bolder and more different, then expands the five that differ most. |
| `dotgrill` | "Grill me" on a plan, design, or idea: maps its decisions as a tree, asks every question that is ready in numbered rounds with a recommended answer for each, looks facts up itself, and stops when nothing is left assumed. Adapted from Matt Pocock's [grill-me](https://github.com/mattpocock/skills/tree/main/skills/productivity/grilling) (MIT). |

## Install

```
/plugin install dotopen --marketplace pooryam92/dotclaude
/plugin install dotupdate --marketplace pooryam92/dotclaude
/plugin install dotbrainstorm --marketplace pooryam92/dotclaude
/plugin install dotgrill --marketplace pooryam92/dotclaude
```

## Update

```
/dotupdate
```
